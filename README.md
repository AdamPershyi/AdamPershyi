I recently completed the **Fullstack Developer** program at [IT School GoIT](https://goit.global) (2025–2026), contributed to several Agile/Scrum team projects, and deploy my work to Vercel and GitHub Pages.

## Featured projects

### [nmt.in.ua](https://nmt.in.ua/) — NMT math prep platform
Team product built with **Next.js, React, and TypeScript**. An online trainer for Ukraine's National Multi-subject Test: diagnostics, topic practice, exam simulation, and student/teacher dashboards.

I contributed the marathon **leaderboard**, **mobile** results/session views, **site feedback** ratings with an admin list, and a **topic-test timer**.

[Live](https://nmt.in.ua/) · [Vercel](https://nmt-in-ua.vercel.app/) · [Repository](https://github.com/tony-kobs/nmt.in.ua)

### [Sweet Workshop](https://tony-kobs.github.io/sweet-deploy-team/) — confectionery landing
Team project (**HTML, CSS, JavaScript**). A responsive SPA for a dessert shop, with sliders, animations, and modal windows. I built the **FAQ accordion** section.

[Live](https://tony-kobs.github.io/sweet-deploy-team/) · [Repository](https://github.com/tony-kobs/sweet-deploy-team)

### [CoffeeJoy](https://tony-kobs.github.io/JoJo-team-project/) — coffee shop landing
Team project (**HTML, CSS, JavaScript**). A responsive one-page site with smooth animations, menu-preview modals, and interactive UI. I built the **Gallery** section, fixed the experience block, and added a **scroll-up** control.

[Live](https://tony-kobs.github.io/JoJo-team-project/) · [Repository](https://github.com/tony-kobs/JoJo-team-project)
